# YHSJ 界面定制

用户可见的产品名称、登录页与侧栏标识、浏览器标题及图标使用 YHSJ。
多语言文案保持相同的键名，避免破坏已有功能。

兼容性边界：Go module、CLI 二进制名、API 路径、协议字段、环境变量、
浏览器存储键以及第三方服务地址仍保留原标识。它们不是产品品牌展示，
不可通过全文替换更名，否则会导致旧客户端、数据或集成失效。
开源许可证、版权声明及第三方归属信息保留；业务数据和用户生成内容不批量修改。

本次只修改源码，不自动更新运行镜像或现有部署。

## 问答与助手身份

快速问答、知识库问答、闲聊与追问、模型兜底和智能体的内置提示词统一使用 YHSJ，
不再把上游项目或厂商当作当前助手身份。内置助手的名称、角色说明及模型可见的工具文案同步调整。

旧版本可能把内置模板正文保存进智能体配置。生成回复前只更新可识别的旧版自我介绍，保留其余提示词、
自定义业务规则及真实的第三方名称、引用与署名。不改写数据库、历史消息、文档或流式回答，也不改 API、
工具名和路径等兼容标识。未识别的自定义提示词若仍写着旧身份，应由管理员核对并定点调整。
测试服更新后建议新建会话，分别问“你是谁？”并重问之前出现旧品牌的业务问题；遇到旧名时，区分是助手自称，还是有依据的来源引用。

## 账号邮箱选填

公开注册、邀请链接注册及管理员创建账号时，邮箱可省略，存储为空字符串；
不伪造内部邮箱。多个无邮箱账号可共存，以唯一用户名登录。填写时仍验证格式，
非空邮箱保持唯一并兼容邮箱登录；按邮箱定向邀请仍需要真实邮箱。
管理员重置密码优先使用用户 ID，兼容旧邮箱请求，无邮箱用户也可重置。
需应用 PostgreSQL 139 / SQLite 55 的邮箱索引迁移；本次不在线执行。
迁移保留已有用户、密码散列与权限。多个空邮箱存在时 down 迁移拒绝回退，
不能通过删除用户或伪造邮箱规避；应先由管理员补齐邮箱再评审回退。

## 内网密码规则

默认复杂密码开关关闭时，只要求非空、合法 UTF-8、最多 72 字节（bcrypt 限制），
不再有 8 位、字母或数字组合要求。支持单字符、纯数字、纯字母和中文；
空白是密码的一部分，不做 trim，不允许空字符串。登录不应用新密码强度规则，
保留旧账号兼容；修改 / 重置仍撤销旧会话，自助修改仍验证原密码。
管理员手动打开“启用复杂密码”后，继续执行原有 8–32 字符与四类字符规则。
这不是免密码登录，管理员自动生成的密码仍使用安全随机值。短密码只适合受控内网，
建议网络隔离、限制登录入口并使用 HTTPS；本轮不改在线复杂密码开关。

## 管理员创建账户直接分配空间

系统管理员在创建账户时选择已有的默认空间和空间权限（只读 viewer / 编辑
contributor / 管理员 admin / 所有者 owner），默认权限为只读。新界面要求选择空间；
创建后直接成为该空间的 active 成员并将其作为首次登录空间，不创建个人空间、
不发送邀请。不授予系统管理员或跨空间超管权限。

`POST /api/v1/system/admin/users/create` 新增 `default_tenant_id` 和 `role`，必须成对传入，
未传时兼容旧客户端原有初始化策略。账户和成员记录在同一个事务中提交，
无效 / 已停用 / 已删除空间或成员写入失败不会留下半成品账户。
相同用户名 / 邮箱 / 默认空间 / 现有 active 角色的重试返回已有账号，
不再次返回随机密码；角色或空间不同返回冲突，不修改已有用户权限。

`GET /api/v1/system/admin/users/workspaces?keyword=...&page=1` 返回供创建选择的
空间名称与 ID（每页 100，支持名称搜索），仅系统管理员认证可访问，
不要求另有跨空间超管标志，不向客户端返回模型 / 存储 / 凭据等空间配置。
无需数据库迁移；本轮仅源码及隔离测试，不在线创建账号或更新测试服。

## 已有账户提示与审计展示

管理员重复提交已有账户时，沿用 HTTP 200 的幂等响应，但显示普通信息提示：
“账号 {username} 已存在，本次未创建，也未更改密码或权限。”不使用创建成功提示，
也不再次展示随机密码。真正新建仍返回 HTTP 201 和创建成功提示。

新审计使用 `system.user_already_exists` 区分真正 `system.user_created`；
平台审计列表及详情显示“账号已存在（未创建）／未更改”。历史
`system.user_created` + `details.idempotent=true` 仅在界面按相同语义解释，
不修改存储的事件、时间、操作者或详情，不执行审计数据迁移。

## 账号密码保存

登录页使用“保存账号密码”复选框，勾选表示保存，取消勾选清除已记住的账号。仅在验证成功后记住账号，
并通过 Credential Management API 请求浏览器保存密码（需 HTTPS / localhost
及浏览器支持）。不支持或拒绝保存时提示使用浏览器自带的保存密码功能。
应用不把密码写入 localStorage、sessionStorage、日志或服务器偏好。
“取消保存”清除本机记住的账号；已经保存到浏览器的密码需在浏览器密码管理器删除。

## 用户名 / 邮箱登录

登录接口 `POST /api/v1/auth/login` 的 `email` 字段现在接受用户名或邮箱，
仅去除账号首尾空白，密码不做改写。包含 `@` 时按邮箱精确查找，否则按用户名
精确查找；用户名区分大小写，沿用已有唯一性规则。不自动注册、不回退匹配其他账号。
未知账号与密码错误返回相同错误；禁用账号仍不可登录。无需数据库迁移。

## 隐藏发布集成

所有角色（包括系统管理员）均不显示设置中的发布集成分组及其全部面板。
旧的 `integrations`、`integration-*`、裸 tab 链接和设置快捷事件统一回退常规设置，
不依赖能力数据加载完成，也不挂载集成组件。智能体编辑器中的渠道配置快捷入口
和计数请求同步移除。MCP 客户端工具、技能及智能体共享功能不受影响。
这属于界面策略，不删除已有渠道 / Token / 数据，不停用后端集成 API。

## 隐藏云服务菜单

所有角色（包括系统管理员）隐藏模型分组中的 YHSJ Cloud 云服务设置菜单，
不导入或挂载该面板，旧 `section=weknoracloud` 链接回退到常规设置。
仅隐藏独立的云服务配置菜单，不删除已保存的模型 / 凭据，也不隐藏普通远程模型。

## 首页自动化 / 工具箱菜单

系统管理员在「系统管理 → 系统设置 → 访问与注册」可以分别控制自动化菜单和普通成员的工具箱菜单。
两个开关默认关闭。系统管理员、跨空间管理员和当前空间管理员／所有者始终看到工具箱；普通成员只有在
开关开启时看到。工具箱内部仍按原有角色和部署能力显示工具。自动化开关仍对所有角色生效。
沿用 `ui.navigation.automations_visible` 和 `ui.navigation.toolbox_visible`，无需迁移或重启。
其他用户刷新后读取新状态；工具箱开关读取失败时不向普通成员显示。菜单开关不改变后端权限、既有任务或工具配置。

## 普通成员菜单与设置

普通成员（当前空间的 viewer／contributor，且没有平台管理权限）保留新对话、历史对话、知识库、文档中心，
工具箱和自动化按各自开关显示。知识库默认打开全部可访问的库，不在列表提供新建入口。
头像菜单保留个人设置与退出。左下角显示「账号 · 部门」，部门来自组织目录；未分配时显示「未分配部门」。
部门由 `/auth/me` 返回，不借用空间角色或名称。新版前端遇到缺少该字段的旧后端时使用未分配提示。
左下角空间切换默认隐藏；系统管理员可在「系统设置 → 访问与注册」开启「允许普通用户切换空间」
（`ui.navigation.workspace_switcher_visible`），开启后只显示已分配空间，且至少有两个才显示切换入口。
设置仅显示常规设置和用户信息（包括修改密码）；助手、沙箱密钥、凭据保险库、空间、模型和版本信息均隐藏。
旧管理设置链接回到常规设置。管理员原有设置及权限不变。
不显示智能体管理快捷入口，但不影响对话中选择已授权的智能体；不改变后端权限或 Lite 的个人工作流。

## 组织管理布局

部门树常驻左侧。新增部门、编辑所选部门、新增子部门和删除都在部门侧；人员区不重复展示部门名，
只放搜索、筛选、刷新、创建账号和调整成员归属等操作。窄窗口时部门树移到人员表上方。
主要创建操作用实心按钮，辅助操作用描边按钮，删除和停用保留危险色与确认。

- 前端全量单测、类型检查、生产构建；后端 service / handler / types 包测试及 go vet。

- WebKit 隔离静态构建烟测：1440、768、390、320 宽度，检查水平居中、
  横向溢出、保存开关与用户名请求提交；API 使用模拟返回，不连接业务数据库。
- 尚未验证真实账号登录、真实浏览器密码库写入或部署后的端到端行为。
- 前端复用本机已有依赖，未重新安装；不是一次新的 lockfile 依赖安装验证。
