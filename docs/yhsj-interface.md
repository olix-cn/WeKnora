# YHSJ 界面定制

用户可见的产品名称、登录页与侧栏标识、浏览器标题及图标使用 YHSJ。
多语言文案保持相同的键名，避免破坏已有功能。

兼容性边界：Go module、CLI 二进制名、API 路径、协议字段、环境变量、
浏览器存储键以及第三方服务地址仍保留原标识。它们不是产品品牌展示，
不可通过全文替换更名，否则会导致旧客户端、数据或集成失效。
开源许可证、版权声明及第三方归属信息保留；业务数据和用户生成内容不批量修改。

本次只修改源码，不自动更新运行镜像或现有部署。

## 账号邮箱选填

公开注册、邀请链接注册及管理员创建账号时，邮箱可省略，存储为空字符串；
不伪造内部邮箱。多个无邮箱账号可共存，以唯一用户名登录。填写时仍验证格式，
非空邮箱保持唯一并兼容邮箱登录；按邮箱定向邀请仍需要真实邮箱。
管理员重置密码优先使用用户 ID，兼容旧邮箱请求，无邮箱用户也可重置。
需应用 PostgreSQL 139 / SQLite 55 的邮箱索引迁移；本次不在线执行。
迁移保留已有用户、密码散列与权限。多个空邮箱存在时 down 迁移拒绝回退，
不能通过删除用户或伪造邮箱规避；应先由管理员补齐邮箱再评审回退。

## 账号密码保存

登录页使用“保存账号密码”复选框，勾选表示保存，取消勾选清除已记住的账号。仅在验证成功后记住账号，
并通过 Credential Management API 请求浏览器保存密码（需 HTTPS / localhost
及浏览器支持）。不支持或拒绝保存时提示使用浏览器自带的保存密码功能。
应用不把密码写入 localStorage、sessionStorage、日志或服务器偏好。
“取消保存”清除本机记住的账号；已经保存到浏览器的密码需在浏览器密码管理器删除。

## 用户名 / 邮箱登录

登录接口 `POST /api/v1/auth/login` 的 `email` 字段现在接受用户名或邮箱，
仅去除账号首尾空白，密码不做改写。包含 `@` 时按邮箱精确查找，否则按用户名
精确查找；用户名区分大小写，沿用已有唯一性规则。不自动注册、不回退匹配其他账号。
未知账号与密码错误返回相同错误；禁用账号仍不可登录。无需数据库迁移。

## 隐藏发布集成

所有角色（包括系统管理员）均不显示设置中的发布集成分组及其全部面板。
旧的 `integrations`、`integration-*`、裸 tab 链接和设置快捷事件统一回退常规设置，
不依赖能力数据加载完成，也不挂载集成组件。智能体编辑器中的渠道配置快捷入口
和计数请求同步移除。MCP 客户端工具、技能及智能体共享功能不受影响。
这属于界面策略，不删除已有渠道 / Token / 数据，不停用后端集成 API。

## 隐藏云服务菜单

所有角色（包括系统管理员）隐藏模型分组中的 YHSJ Cloud 云服务设置菜单，
不导入或挂载该面板，旧 `section=weknoracloud` 链接回退到常规设置。
仅隐藏独立的云服务配置菜单，不删除已保存的模型 / 凭据，也不隐藏普通远程模型。

## 首页自动化 / 工具箱菜单

两个入口对所有角色默认隐藏。系统管理员在「系统管理 → 系统设置 → 访问与注册」
中可以分别设置“显示自动化菜单”和“显示工具箱菜单”。设置保存在已有全局设置表中，
无需数据库迁移或重启。键名为 `ui.navigation.automations_visible` 和
`ui.navigation.toolbox_visible`，均为布尔值，默认 false。
保存 / 重置后当前管理员的侧栏立即刷新；其他用户刷新页面后读取新状态。
能力接口加载失败、旧版后端没有新键时保持隐藏。只控制导航入口，不取消既有任务、
不删除工具配置、不撤销后端权限，也不禁止直接访问已有路由。

## 只读用户的智能体导航

当前空间角色为 viewer（只读）时隐藏首页智能体菜单及命令面板的智能体列表快捷入口。
角色尚未加载时也不展示；切换空间后按当前空间角色立即重算。contributor / admin /
owner 保留入口。仅隐藏列表管理导航，不改变后端 RBAC，不影响聊天中使用已有智能体。

## 验证范围

- 前端全量单测、类型检查、生产构建；后端 service / handler / types 包测试及 go vet。
- 用户名 / 邮箱 / 错误密码 / 未知或禁用账号的 mock 登录与定向 race 测试。
- WebKit 隔离静态构建烟测：1440、768、390、320 宽度，检查水平居中、
  横向溢出、保存开关与用户名请求提交；API 使用模拟返回，不连接业务数据库。
- 尚未验证真实账号登录、真实浏览器密码库写入或部署后的端到端行为。
- 前端复用本机已有依赖，未重新安装；不是一次新的 lockfile 依赖安装验证。
