# 图纸套件 EBOM 与聊天模板生成

## 模板与业务边界（2026-11-12 修正）

模板库是业务中立的共享模板管理能力，只描述工作簿、栏目、样式和不可变发布版本，不代表 BOM／EBOM 类型。生成什么由用户任务决定，业务适配器负责数据来源、校验、计算、字段映射和输出命名。本文只约定独立 EBOM 适配器，不能将其规则应用于所有模板任务。

通用 `document_templates` 查询只返回模板元数据和原始栏目，不按 EBOM 表头标记支持与否，也不默认指向 BOM 数据读取。`generate_ebom` 仅用于用户明确提出的 EBOM 任务。当前没有通用任意业务生成器，不能因为模板可以上传／发布就宣称任何业务都能自动生成。总装配命名、生产台数、一套图纸等只属于 EBOM 业务规则。

> 后续状态：取消自动附加工作表与总装配文件命名已于 2026-11-12 部署测试服，对新任务生效；以下规则中的“未部署”为实现时历史记录，详细状态见 document-center-progress.md。

> 2026-11-12：已按受限范围实现并隔离移植至测试服，真实 CAD 业务端到端待验收。取代模板 EBOM 场景的“聊天手抄表／Skills 临时脚本”路径，证据不足不宣称完整。

## 用户操作

1. 管理员上传模板、确认表头、试填、发布；已发布卡片置顶，右侧预览抽屉，不显示内置示例或会话导入表单。
2. 聊天要求“读取此文件夹的一套图纸，按某模板生成 EBOM，生产 N 台”。未指定台数必须询问，不从模型猜测。
3. Agent 调用已发布模板目录，读取 MCP 的完整 schema/data 页集，再调用程序预检／生成入口，不提交表格值或脚本。
4. 程序按精确图号建立关系，自动找唯一无上级总成。无唯一根、环、重复图号版本、多套不连通结构或数量错误时停止；未检测字段、缺失结构证据不能标“完整”。
5. 返回任务文件链接与完整性说明；部分结果须用户明确接受，不自动降级为完整 EBOM。

## 固定计算口径

- 选定目录约定是一套图纸，但这不是完整性的证据。结构需验证唯一根、无环、可达性及必要身份信息。
- 默认提供层级 EBOM（不等于采购汇总）：同件在不同父总成下保留不同结构路径，不把父总成和子零件重复计入采购合计。
- 源明细“数量”按每个直接父总成用量。单台数量＝路径上逐级用量乘积；多台数量＝单台数量×生产台数。用十进制有理数计算，不执行上传文件中的 Excel 公式。
- 同名不是同件。物料／图纸编号精确匹配，名称仅显示。版本冲突、重复文件／多表身份歧义拒绝自动选择；没有权威图号时只允许独立文件名编号作为候选，注明身份依据及无法验证的限制。
- 来源数据必须从 MCP 结构化结果读取；图号、版本、零部件类型、数量口径等若无源证据，不能由模型填写成事实。已有 MCP 无完整类型信息时只能输出受限版本，不能宣称缺图已排除。
- 自定义模板可按固定栏目含义投影（序号、层级、父项、图号／代号、名称、材料、数量／单台数量、多台数量、单重、总重、备注）；不支持的栏目需明确说明，不猜测单位／重量含义。
- 模板“数量”统一展示单台展开量；直接父项的源用量另列“本级数量”用于审计。单重／总重现阶段只保留源表值，不把多台数量乘进来源总重；重量单位及计算口径未定义前不承诺自动重量计算。未知版本／材料等目标栏按未检测输出且需接受部分结果。
- 按用户最新命名要求，下载文件使用 `根总装配图号-名称-YYYYMMDDHHmmSS.xlsx`，时间按任务创建时北京时间；任务重试不重新命名，部分状态由任务与聊天说明。命名变更源码已修，未部署，不重命名既有产物。
- 按用户 2026-11-12 最新要求，输出仅保留模板原有工作表，不再自动附加来源／说明／状态表；来源数据和计算依据保留于私有数据集，聊天返回限制与完整性说明，任务仍标识部分结果。此取消附表变更源码已修，未部署；不自动删除或重写历史文件。

## 权限与稳定性

- 模板目录／预览只对当前空间的已发布版本开放；草稿预览仅创建者管理员。
- 聊天入口绑定当前真实用户、空间、会话与消息；不接受模型传入其他用户／会话、任意数据值或路径。
- 当前轮数据仅由引擎传递已完成工具结果的只读快照；分页须齐全，不经模型抄写。持久化后下载仍复查源消息和会话权限。
- 生成幂等、固定预算、发布版本不可变、停用不影响旧文件规则保留；模板预览为鉴权 Blob，无公开原文件 URL。

## 边界

不修改 CAD、不安装依赖、不自动部署；原生 Mechanical BOM 适配和 MCP 新结构字段需按真实契约验证，不能把图面显示表自动升级为原生 BOM。
