# YHSJ 文档中心：模板库与文档生成业务流程方案

> 状态：已开始分阶段实现，完整业务流程尚未贯通。日期：2026-11-11。
> 首期场景：将 CAD MCP 取得的 BOM 数据填入 Excel 模板，生成网页可下载文件。
> 本文约定的是建议产品行为，不代表现有 YHSJ、MCP 或 Excel 引擎已经支持这些能力。
> 入口结构已按评审意见调整：统一使用“文档中心”，下设“我的文件 / 模板库 / 生成任务”，不新增独立的“文档生成”菜单。
> 已实现范围、未开放能力及验证限制见 [实现进度](../document-center-progress.md)；下文仍为完整目标方案，不代表所有步骤都已可用。
> 第三阶段已接入受限自定义 Excel 的上传、手填坐标配置、合成试填、不可变发布和明确来源列绑定；尚无聊天内卡片、Agent 推荐及实时 MCP 快照接入。已于 2026-11-11 隔离移植到测试服运行基线，真实业务操作待验收。

## 1. 首期要让用户完成什么

### 1.1 最终操作体验

工程师在聊天中输入：

> 读取这个目录的全部图纸 BOM，用公司的工程明细模板生成 Excel。

系统完成数据读取，展示一张“生成文档”卡片，用户只需要处理真正未确定的内容：

- 选择模板；已有明确模板时不再重复选择。
- 补充项目名称等本次文档信息。
- 查看缺失数据，选择先补查还是明确生成部分数据版。
- 点击生成，完成后直接下载。

用户不需要看 JSON、填写 `result_id`、编写 Python、进入沙箱或转交另一个 Agent。

模板管理员只在首次接入模板时配置一次字段和明细区域。以后相同类型的数据可以重复使用。

### 1.2 首期做与不做

| 做 | 不做 |
| --- | --- |
| Excel `.xlsx` 模板上传、配置、试填、发布和停用 | 任意 Excel 都零配置自动理解 |
| BOM 数据接入、字段适配、完整性检查 | Word、PPT、PDF 渲染 |
| 用户选模板、Agent 推荐模板 | 自主联网寻找并使用未经审核模板 |
| 单一明细重复区域、固定说明页与文件状态页 | 多套循环嵌套、跨表复杂报表引擎 |
| 固定渲染器生成并验证 Excel | Agent 每次重新编写脚本 |
| 复用现有文件库、当前会话下载、本人生成任务 | 自动发送邮件、上传 ERP、保存回工作站 |
| 保留来源、未检测、歧义和部分结果标识 | 自动补出材料、重量、单价或原生 BOM 数量 |

**首期默认产物是网页下载附件，不同时执行工作站目录导出。** 需要工作站保存时，用户下载后自行保存；后续再增加明确的“保存到工作站”操作。

## 2. 角色与权限

不新增一套与空间无关的账号体系。下表的能力最终映射到现有空间权限；角色名称为业务称呼。

| 操作 | 空间管理员／被授予模板管理权限者 | 普通成员 | 只读成员 |
| --- | --- | --- | --- |
| 查看本空间已发布模板、预览样式 | 可以 | 可以 | 可以 |
| 上传、配置、试填模板 | 可以 | 首期不可以 | 不可以 |
| 发布、设为默认、停用模板 | 可以 | 不可以 | 不可以 |
| 使用已发布模板生成文档 | 可以 | 可以 | 建议可以，但必须具备所选数据的读取权限 |
| 查看、下载自己生成的文件 | 可以 | 可以 | 建议可以，遵守附件读取权限 |
| 查看别人的文件内容 | 不自动赋予 | 不自动赋予 | 不自动赋予 |

“只读成员可生成”指将其有权读取的数据转换成下载文件，不包含修改图纸、发布模板或写入外部系统。若现有权限体系不允许创建附件，应新增明确的生成能力判定，不能通过后端旁路放行。

首期仅空间内共享已发布模板。不做跨空间模板发布和“管理员可查看所有生成文件”；模板可见不代表业务数据可见。

## 3. 页面与入口

### 3.1 入口位置

将现有“产物”一级菜单扩展并更名为 **“文档中心”**，不同时保留“产物”和“文档生成”两个一级菜单。

```text
文档中心
├── 我的文件       默认页，沿用现有产物库
├── 模板库         选择模板；有权限者配置和发布模板
└── 生成任务       跟踪模板生成过程，处理待补充和失败任务
```

页面副标题：**“按模板生成文档，管理聊天与任务生成的文件。”** 右上角主按钮为“使用模板生成”。

“文档中心”侧重 Excel、Word、PDF 等业务文档，但不删除或隐藏原产物库中的图片、代码包及其他文件，它们仍在“我的文件”按类型查找。知识库管理作为问答依据的源资料，文档中心管理生成和交付的文件；首期不合并两者，也不将文档中心做成任意文件网盘。

| 页签 | 显示内容 | 主要操作 | 不承担的职责 |
| --- | --- | --- | --- |
| 我的文件 | 原有可访问的聊天产物、已发布的模板生成文件 | 搜索、分类、预览、下载、删除、查看来源 | 不列空文件、失败任务或模板草稿 |
| 模板库 | 已发布模板；管理员另可查看草稿和停用版本 | 使用模板、预览、配置和发布 | 不收纳用户生成的业务文件 |
| 生成任务 | 首期仅模板生成任务，含待补充、生成中、失败及已完成 | 继续填写、重试、取消、查看文件 | 不把全部聊天执行日志改造成任务，不再复制文件管理功能 |

进入文档中心默认打开“我的文件”；访问已保存的模板／任务深链接时保留目标页签。生成任务完成后通过“查看文件”打开同一文件详情，预览、下载和删除复用“我的文件”能力。

同时提供聊天内入口：

- 输入框操作菜单：“使用模板生成文档”。
- BOM 数据结果卡：“用模板生成 Excel”。
- Agent 推荐卡：“使用此模板”。

所有入口复用同一生成流程。管理员从“模板库”配置，不要求打开智能体设置；只读成员也不依赖智能体管理菜单。从模板库开始生成不强制新建聊天会话。

各入口及页签按实际文件读取、文档生成、模板管理权限显示；不能继续仅用“是否开启沙箱”控制整个文档中心的可见性。固定渲染器不依赖沙箱时，无沙箱用户也应能使用其获准的能力。只有文件查看权限者可进入“我的文件”，没有生成权限时隐藏生成按钮；后端仍需逐项鉴权，不因菜单可见而授予数据权限。

### 3.2 模板库列表

卡片显示：模板名称、用途、Excel 格式、发布版本、最近更新时间、样式缩略图、是否默认。

提供搜索名称／标签，按用途和发布状态筛选；普通用户不显示草稿和已停用版本。

用户按钮：`查看模板`、`使用模板`。

管理员额外按钮：`上传模板`、`新建版本`、`停用`、`设为该用途默认`。

模板详情显示“需要的数据”和“不能处理的情况”，例如：

> 工程 BOM 明细 v1：支持多图逐行合并，不执行数量汇总；不支持重量计算。必须取得图号和名称，数量缺失时只能生成部分数据版。

### 3.3 生成向导

统一采用四步，聊天中以卡片／抽屉打开，独立页面可显示完整布局：

```text
选择数据 → 选择模板 → 检查与补充 → 生成结果
```

从数据卡进入时跳过已完成的“选择数据”；从模板卡进入时带入模板，但仍需检查实际适配性。

### 3.4 现有产物如何迁入

- 原产物的文件、分类、搜索、预览、下载、删除、来源会话和既有文件版本功能继续保留，入口名称改为“文档中心 → 我的文件”。不重新复制文件、不要求用户重新生成。
- 旧“产物”路由／书签／快捷入口继续解析到“我的文件”，并保持已有权限检查；聊天中的旧下载链接不因菜单调整失效。
- 不要求历史产物补齐模板、数据集或生成任务。历史文件仍显示“聊天生成”，来源按钮返回原会话。
- 模板原件、草稿及配置归“模板库”，不混进“我的文件”。真实数据试填文件保持私有，不作为公开模板预览。
- 完成的模板任务只将文件登记到同一文件库，任务与聊天卡片引用同一文件；不得建立各自一份文件副本和独立删除逻辑。
- 独立模板任务以真实任务作为文件来源，不为兼容旧会话附件接口而伪造聊天。无会话的文件不显示“返回会话”，改为“查看生成任务”。

## 4. 管理员如何把现有 Excel 变成模板

### 步骤一：上传与基础检查

管理员点击“上传模板”，选择 `.xlsx`，填写名称和用途，例如“工程 BOM 明细”。

建议首期上传上限 10 MiB、20 张工作表，具体阈值在实现前压测确认并可配置。超限直接解释原因，不静默删除工作表。

上传后系统先检查，结果只在配置者可见：

| 情况 | 页面反馈 |
| --- | --- |
| 合法、支持的工作簿 | 进入配置 |
| 加密／密码保护导致不能解析 | 提示上传无密码的模板副本 |
| `.xls`、`.xlsm`、宏、外部数据连接等首期不支持内容 | 拒绝或列出不支持项，请用户另存为受支持副本；不能悄悄删掉后发布 |
| 包含嵌入对象或无法稳定保真的功能 | 列明具体工作表／对象，阻止发布，用户调整后再试 |

模板中原有的业务示例数据不得直接当成未来导出的真实数据。系统标记候选示例区域，管理员确认清除范围；未经确认不自动删除。缩略图来自清理后的试填副本，不公开上传原件预览。

### 步骤二：标记填充位置

页面左侧为 Excel 网格预览，右侧为“字段与区域”。网格点击用于选取位置，不做完整在线 Excel 编辑器。

管理员依次标记：

| 区域 | 用户操作 | 例子 |
| --- | --- | --- |
| 固定信息 | 点击单元格，选字段 | B2=项目名称，H2=生成日期 |
| 明细表头 | 选定表头行或多级表头范围 | A5:H6 |
| 明细样板行 | 选定一行，确认按数据条数复制 | A7:H7 |
| 明细列 | 点击每一列，选择业务字段 | A=序号，B=图号，C=名称 |
| 文档说明 | 选择现有位置或使用系统附加页 | 读取说明页 |

首期只支持一个重复明细区域。页脚、合计行、打印区域会在试填时检查；无法可靠移动的合并区域／对象阻止发布。模板作者可在 Excel 离线修改后重新上传，系统不承诺自动修复排版。

支持 `{{项目名称}}` 等占位符作为辅助识别方式，但普通用户不必学习占位符语法；最终保存的是管理员确认后的字段绑定。

### 步骤三：配置每个字段的来源与要求

管理员从菜单选择来源，不写代码：

- **数据字段**：图号、名称、数量、材料、来源图纸等。
- **本次填写**：项目名称、订单号、编制人等。
- **系统字段**：生成日期、文档编号等；文档编号须有已定义规则，首期可只支持任务编号。
- **固定值**：公司名称、部门名称等。

每个字段指定：显示名、类型、是否必填、缺失时是否允许明确标注。展示用默认值与业务值分开：空白项目名可显示“未填写”，未检测到数量不能默认填 0。

“模板字段对应关系”属于持久规则，例如 `图号 ← part_number`；“这次的项目名称”只属于本次任务。不能把一次人工填写自动写回模板默认值。

### 步骤四：检查 AI 建议，不直接采纳

管理员可点击“自动识别配置”。Agent 建议候选字段和重复区，页面标为“待确认”。

示例：

```text
零件代号 → 图号         建议接受
品名     → 名称         建议接受
采购数量 → 装配数量     语义不同，待确认，不能直接映射
```

管理员逐项确认或修改。没有被确认的建议不进入已发布版本。被拒绝的建议不会在下一步被 Agent 自动重新填回。

### 步骤五：试填与预览

默认使用合成样例；管理员可选择本人有权读取的数据试填。真实数据试填产物为私有，不变成模板公开示例。

至少检查三种行数：无明细、少量明细、多行跨页。用户查看：

- 第一页／末页、表头、页脚是否正确。
- 明细行扩展后列宽、格式、筛选、冻结区域是否保留。
- 图号前导零、中文、长名称、缺失标识是否显示正确。
- 模板原有示例行是否已清除，未填字段是否泄漏旧值。

页面预览优先为可查看数据值的工作簿网格和验证摘要，下载试填文件供用户用 Excel 核对打印。首期不承诺网页预览与 Excel 打印分页完全一致，也不依赖未建设的 PDF 转换。

### 步骤六：发布版本

发布前必须通过：必填绑定完整、无未知占位符、重复区合法、试填校验成功、样例数据清理确认。

发布后产生固定版本，例如“工程 BOM 明细 v1”。用户不能直接修改已发布版本：点“新建版本”复制为 v2 草稿，试填后发布。旧生成文件和任务始终绑定原版本。

停用只阻止新任务选用，不删除历史文档。被安全隔离的模板版本可阻止尚未开始的任务，系统提示改选；已完成文件按原有访问与保留规则处理。

## 5. 工程师在聊天里生成 BOM Excel

### 步骤一：确认数据范围

从用户问题提取明确范围，卡片显示：数据源、工作站目录／文件、是否含子目录、保存显示表还是原生 BOM。

如果用户已经写明“不含子目录”，直接使用；如果只是“这个目录全部图纸”，采用明确标注的本层默认范围，不自行递归，用户可修改。

读取 BOM 直接使用具备表结构能力的数据源，不固定先获取通用图纸全部块／引用。用户无需选择 MCP 工具名，`result_id` 不展示在正常操作界面。

读取后显示：文件数、成功读取数、表数、明细行数、数据源类别和问题计数。无权访问或连接不可用时，先处理连接，不能跳过读取直接套样例生成。

### 步骤二：选择或推荐模板

优先级：

1. 用户明确指定且有权限的模板版本。
2. 用户确认沿用的上次模板。
3. 当前空间该用途的默认模板。
4. Agent 推荐最多 3 个候选，由用户选择。

只有一个有效默认且适配时，卡片自动选中，用户无需单独回复“选这个”。不自动替换用户指定的模板；不适配时解释缺什么，让用户修改选择。

推荐理由必须具体，例如“支持多图逐行合并并保留来源列”，不要只写“最适合你”。

### 步骤三：填写文档信息与映射检查

页面只显示需要用户处理的项目：

```text
项目名称：________      可选
编制人：当前用户        可修改为显示文本，不冒充电子签名
图号 → 零件代号         已验证的映射规则
名称 → 零件名称         已验证的映射规则
采购数量 → 未提供       必填，需换模板或明确补充采购数量
```

用户调整映射时，必须选数据里实际存在且语义适合的字段。歧义字段可展开来源证据；不能只因位置相同就绑定。允许“保存为本空间适配规则”需模板管理权限，并经单独确认；普通用户只改当前任务。

### 步骤四：处理完整性问题

将问题分成三类，不把所有 warning 都弹确认：

| 类型 | 行为 |
| --- | --- |
| 不能安全生成：数据无权访问、未取全页、快照失效、模板损坏、必填字段无映射 | 禁止生成，显示修复动作 |
| 可生成受限结果：未检测单元格、未解决列语义、部分文件无表／读取失败、用户手工补充 | 用户查看范围后，可明确生成部分数据版，产物持续标记 |
| 已验证不影响本次任务的兼容性通知 | 折叠显示类别和数量，不单独询问 |

“缺字段”和“缺值”分别展示。例如模板已绑定数量字段，但某三行没有可靠数量，这不是再选一次字段能解决的问题。

部分结果卡示例：

```text
已读取 3 张图纸，发现 2 张明细表，共 12 行。
数据源：已保存图面明细表，未读取原生 BOM 数据库。
40 个单元格未检测到文字，4 个列语义待核实。
1 张图纸未发现已保存明细表。

[补查具体问题] [更换模板] [生成部分数据版]
```

点击“补查具体问题”只调用针对性的表头／单元格证据接口，不重读全部图纸。补查不能解除问题时，保留原状态，不循环重试。

用户手工补值必须与机器读取值分开：记录填写人、原状态及修改值，导出说明标为“人工补充”，不改 CAD，也不把该值写回原读取快照。跨任务复用需用户再次明确选择。

### 步骤五：一次确认与开始生成

最终卡片一次列出：模板版本、数据范围、合并方式、行数、已填文档信息、问题及输出级别。

- 完整数据：点击“生成 Excel”。
- 部分数据：点击“生成部分数据版”，即为接受页面已列出的受限范围。

点按钮后不再让 Agent 另问一次“确认吗”。数据或模板变化则原确认失效，更新预检卡后重新点击。平台已有的必要安全审批仍保留，不由文案跳过。

### 步骤六：生成、校验和下载

固定程序使用已确认的数据快照、映射、模板版本生成文件，模型不逐行抄数据，不写脚本，不另启动 Excel 子 Agent。

卡片按真实状态显示“准备数据 → 填充模板 → 校验文件 → 可下载”。没有准确百分比时不伪造进度。

成功后显示：文件名、大小、模板版本、行数、完整／部分、校验范围、下载按钮，并同步登记到“文档中心 → 我的文件”。聊天中的文件卡与文件库使用同一文件记录。提供“查看生成任务”“换模板生成”，不要默认再导出到工作站路径。

最终说明示例：

> 已按工程 BOM 明细 v1 生成部分数据版，12 行。文件与本次读取快照核对通过；未检测值与表头歧义已标注，未验证原生 BOM 数据库。

## 6. 从模板库发起的操作

用户点击模板卡“使用模板”后进入同一向导：

1. 选数据来源：当前有权访问的最近数据结果，或重新读取 CAD 目录。
2. 显示已选结果的来源、生成时间、完整性；不把不同人的结果列给用户。
3. 已过期且未导入 YHSJ 的 MCP 结果，按钮为“重新读取”，不是“强制使用”。
4. 完成字段／信息检查后生成。

首期不同时接入任意知识库问答文本、图片识别和 Excel 上传数据源。后续每类数据源都要定义结构化字段与来源状态，不能把聊天自然语言直接当可信 BOM。

## 7. 模板适配的业务规则

### 7.1 一对多图纸与异构表头

首期 BOM 只支持逐行合并，不自动计算父子装配总用量，不跨图去重。

模板管理者为模板选择两种策略之一：

- **固定业务列**：图号、名称、数量等规范列；所有源列仍在附加的“源表明细”中保存，或明确提示有未纳入的源列。
- **全部原表列**：表结构相同时合并；不同列结构／语义时按来源分表，显示原因，不把同名异义列合并。

用户要求“完整原表”但选了固定六列模板时，必须提示两列未纳入，提供换全列表模板或附加源表页选项；不能仅因生成成功就称完整。

### 7.2 必填与缺失

| 情况 | 允许动作 |
| --- | --- |
| 模板要求填写项目名称，尚未填写 | 在表单补充 |
| 模板数量列必须有值，但源数据未检测 | 补查、明确人工补充，或使用允许部分结果的模板 |
| 材料为可选，源数据已证实空白 | 保留真实空白 |
| 材料未检测，无法确认空白 | 按模板显示“未检测”并保留状态，不能直接变空白冒充正常 |
| 需要采购数量，只有装配数量 | 不自动映射或换算；选择适配模板或补充业务数据 |

### 7.3 公式和统计

第一版不允许上传模板中包含任意公式执行逻辑。发现公式时列明并阻止发布，或由作者移除后上传；不暗中删除。

今后若支持合计，只允许管理员配置白名单规则，明确单位、分组键和业务含义。不能把所有含“数量”的列直接求和。外部数据以文本填充时必须防公式注入。

## 8. 任务状态、失败和重试

| 状态 | 用户看到什么 | 可做什么 |
| --- | --- | --- |
| 待补充／待确认 | 明确缺项和受限范围 | 补充、补查、改模板、取消 |
| 排队／生成中 | 当前阶段、开始时间 | 离开页面、返回查看；生成中可请求取消 |
| 校验中 | 文件已生成，正在核对 | 等待，不提前下载未校验文件 |
| 已完成／部分数据版 | 下载与来源摘要 | 下载、换模板、重新读取后生成 |
| 生成失败 | 具体失败阶段 | 按提示重试，不整轮重跑聊天 |
| 文件保存／交付失败 | Excel生成与否、重试入口 | 只重试文件发布；可复用临时产物时不重复取数 |
| 取消／过期 | 是否曾生成文件及可恢复范围 | 重新发起，不默默恢复已取消任务 |

重复点击生成、SSE 断线、页面刷新不得创建多份相同任务。首次点击后生成任务编号，后续请求查询该任务。

刷新后从“文档中心 → 生成任务”恢复，不要求 Agent 再读一遍模板、数据和技能。任务在文件发布并可访问后才标记为可下载；没有成功文件的任务不在“我的文件”中制造空条目。取消后已完成外部读取不逆向修改图纸；未发布文件按清理规则处理。

失败描述必须可操作，例如“模板明细区域包含不支持的合并单元格，请选择其他模板”，不能统一显示“AI 执行失败”。

## 9. 历史、重新生成与版本变化

### 9.1 文件与任务各自怎样显示

“我的文件”沿用原产物列表，新增模板生成文件的来源信息：

- 文件名、类型、大小、生成时间。
- 来源为聊天生成或模板生成；后者显示模板版本与完整／部分标识。
- “查看来源”：聊天文件回到原会话，模板文件打开生成任务；从聊天发起的模板任务可在详情中继续返回会话。

“生成任务”显示任务名称、数据读取时间、模板及版本、状态、行数、生成时间、数据及文件到期时间；按状态筛选，用于处理进度和异常，不再建设第二份文件列表。

### 9.2 重新下载与重新生成

三个操作区分：

- **重新下载**：取同一个已生成文件，不调用模型和 MCP。
- **换模板生成**：使用保留且仍可访问的同一数据集，创建新任务，不重新读取 CAD。
- **读取最新数据后生成**：重新取得源数据，重新检查，不能继承旧完整性结论或人工确认。

只有关联了可用数据集和模板的文件，才提供“换模板生成”。历史普通产物没有结构化来源时，不因其扩展名为 `.xlsx` 就开放该按钮。

### 9.3 三类版本不混用

模板版本、生成任务和文件版本分别记录：

- 模板发布 v2 不修改 v1 任务及已生成文件。
- 每次用户明确重新生成建立新任务，不因同名就合并不同数据源／模板的文件。
- 保留原聊天产物既有的文件版本语义；新模板任务是否替代旧结果必须有明确业务关系，不能自动沿用“同名即同版本”。

旧任务始终绑定其模板版本和数据快照。默认保留已导入生成数据集及文件 30 天是建议策略，最终需业务确认；界面展示实际到期时间，文件与数据保留期分别可见。过期后不承诺还能“换模板”。

### 9.4 删除与权限变化

普通用户可删除自己的生成结果，受现有保留／审计策略约束。删除入口共用文件库的确认与鉴权规则，不增加任务专属的另一套删除；若涉及既有文件版本，应明确告知删除范围。

删除文件后生成任务保留记录并显示“文件已删除”，移除下载入口，不自动重新生成。删除文件不删除原图纸、共享模板或仍在保留期的数据集；用户确需再次生成时建立新任务并重新检查权限。删除任务记录本身不能悄悄删除可能被其他入口引用的文件。

用户失去空间或数据访问权后，重新下载和再次生成仍需重新鉴权，不能因为持有旧链接继续访问。

## 11. 首期完整业务案例

### 案例 A：数据完整，已有适配模板

1. 工程师选择目录和“工程 BOM 明细”。
2. 系统取得完整数据，自动绑定已发布规则。
3. 工程师补项目名，点击生成。
4. 固定渲染器生成并逐项校验，提供下载。

**应只有一次生成确认，不问导出哪些已明确包含的列，不启动 Excel 子 Agent。**

### 案例 B：12 行、40 格未检测、重量表头歧义

1. 系统展示完整性卡，不把缺失值填 0。
2. 用户点击补查重量列，定向返回证据。
3. 证据仍不足时，用户选择“生成部分数据版”或取消。
4. 文件保留所有物理列，列名保留可证明原文并标注待核实；说明页列出缺口。
5. 不能因换模板消除部分结果标记。

### 案例 C：用户指定采购模板，但数据无采购数量

1. 系统提示“采购数量必填，当前只有装配数量”。
2. 用户换工程模板，或补充明确的采购数量。
3. 人工输入不会改 CAD；产物记录人工补充来源。

### 案例 D：模板在任务生成中更新

1. 当前任务已锁定 v1，继续使用 v1。
2. v2 发布后只影响后续新任务。
3. 用户想用 v2 时点击“换模板生成”，创建新任务，不覆盖旧结果。

### 案例 E：页面断线

1. 后台生成不中断、不重复提交。
2. 页面重新连接，按任务编号恢复状态。
3. 文件已完成时直接提供原文件，不重新运行 Agent。

### 案例 F：用户从原产物入口寻找昨天的文件

1. 用户打开原“产物”书签，进入“文档中心 → 我的文件”。
2. 原聊天文件和新模板文件在同一列表，按类型／来源／文件名查找。
3. 点击聊天文件返回原会话，点击模板文件查看生成任务；预览下载使用同一文件能力。
4. 删除一份模板文件后，关联任务显示“文件已删除”，聊天卡片不再展示失效下载按钮，也不重新生成文件。

## 12. 保证业务流程可用的实现边界

本节只写支撑用户行为的必要约束，不规定数据库表和代码目录。

| 模块 | 必须承担的工作 |
| --- | --- |
| CAD MCP | 输出有范围、权限和有效期的结构化结果、来源状态及定向证据；不负责用户选哪个公司模板 |
| YHSJ 数据接入 | 以真实身份读取所有必要页，形成可复现的数据集；完整数据不进入模型上下文 |
| 模板库 | 保存模板文件、字段、区域、映射和版本；模板不包含可执行脚本 |
| 生成服务 | 固定代码填充，扩展明细行，保留缺失状态，验证后保存附件 |
| Agent | 推荐、解释差异、提示补查；只传结果引用与模板选择，不逐行抄数据和临时编程 |
| 文件服务 | 复用现有产物文件存储、预览与鉴权下载，扩展真实生成任务来源；统一过期、删除与关联状态，不伪造资源链接或聊天会话 |

MCP 的 `result_id` 必须连同对应服务、授权范围和会话解析，不是 YHSJ 直接可访问的本地文件。跨端数据接入需要实现；当前“客户端能展示资源引用”也不等于已经具备附件导入。

当前产物读取和下载与会话／消息关联较紧，菜单也依赖沙箱能力。扩展前需梳理这两处边界：在保持老会话归属校验和旧链接兼容的同时，让独立生成任务以自身归属鉴权，不另起一套孤立文件库。

## 13. 验收：按用户动作检查，不只看接口成功

| 编号 | 操作 | 通过条件 |
| --- | --- | --- |
| T01 | 上传含真实样例行的模板 | 发布前能确认清理；试填及普通用户预览不泄漏样例数据 |
| T02 | 新模板配置重复区与字段 | 不写代码完成配置；未知占位符／非法区域阻止发布 |
| T03 | 发布后改模板 | 必须形成新版本，历史文件不变 |
| T04 | 12 行完整 BOM 用模板生成 | 不执行 Agent 生成脚本，行列和数据逐项一致 |
| T05 | 原始数据有前导零、长中文、公式样式文本 | 保留来源类型与文本，不执行来源公式，不出现旧示例残留 |
| T06 | 12 行部分 BOM 生成 | 未检测与歧义保留；用户明确接受后才生成部分数据版 |
| T07 | 固定六列模板遇到八列原表 | 说明未纳入列，允许附加源表或换模板，不能冒称完整 |
| T08 | 重复点击／刷新／SSE 断线 | 任务和文件不重复，状态可恢复 |
| T09 | 换模板生成 | 复用授权内数据集，不调用 MCP 重新读取，也不改旧文件 |
| T10 | 数据过期／权限撤销 | 不强制使用过期结果或旧下载权限，给出重新读取／无权提示 |
| T11 | Excel 成功生成但附件保存失败 | 明确失败阶段，能在保留期内只重试文件发布 |
| T12 | viewer 使用模板 | 仅能用其有权读取的数据生成，不能管理模板或写源文件 |
| T13 | 打开原产物书签／历史下载链接 | 原文件与权限保留，书签进入“我的文件”，不要求补建任务 |
| T14 | 聊天中按模板生成文件 | 聊天卡片、任务及“我的文件”关联同一文件，不重复存储或列重复行 |
| T15 | 从模板库独立生成 | 不强制创建聊天会话，完成后能在“我的文件”预览下载并返回任务 |
| T16 | 删除模板生成文件 | 任务及聊天卡同步不可下载；不删模板或原图纸，不自动重生成 |
| T17 | 无沙箱但具备文档生成权限 | 仍可使用固定渲染生成及下载，不因原菜单沙箱门槛而被整体隐藏 |
| T18 | 不同任务生成同名文件 | 文件来源和任务独立，不错误合并为同一文件版本 |

性能验收先看过程：无模型搬运整表、无动态脚本、无无意义的全页回读、无重复导出。再用同一数据集／模板测量字段预检、渲染、验证、交付耗时和模型调用数；不承诺在未压测前固定几秒完成。

## 14. 实施顺序与每步可交付成果

1. **统一入口与固定样板闭环**：复用产物库建立文档中心三页签，保持旧入口／链接与权限；开发内置工程 BOM 模板，直接消费结构化数据集，生成文件进入同一“我的文件”，下载与校验正常。不另建文件库，先验证不再出现模型手抄和脚本生成。
2. **管理员模板配置**：实现上传、区域标记、字段绑定、合成试填、版本发布。拿一份业务现有表验证，而不是只验证开发样例。
3. **业务生成向导与任务记录**：接入模板选择、完整性卡、补充信息、部分结果确认、独立任务来源及生成任务页；文件管理复用“我的文件”，处理断线恢复、删除状态和来源跳转。
4. **Agent 推荐和辅助配置**：接入模板检索、权限过滤、适配推荐和待确认建议，不让模型成为生成服务的强依赖。
5. **扩展格式／数据源**：前四步验收后，再评估 Word、其他业务单据和结构化上传数据。

## 15. 开发前需要业务确认的决定

已按用户评审确认的入口方向：一级菜单采用“文档中心”，包含“我的文件 / 模板库 / 生成任务”；原产物功能归入“我的文件”，不再并列增加“文档生成”菜单。此项为设计结论，尚未改动实际界面。

其余以下为建议默认值，评审时可逐项修改，不应在开发中默认为已获批准：

| 决定 | 建议 |
| --- | --- |
| 首期试点 | 工程 BOM 合并 Excel，不先做成本／采购计算 |
| 导出目的地 | 仅网页下载，不同时写工作站 |
| 模板管理者 | 空间管理员及明确授权人员 |
| viewer 能否生成 | 可以，但受数据读取和附件权限限制 |
| 第一份业务模板 | 由用户提供脱敏的现有 Excel，明确固定列或全部原表列策略 |
| 模板不支持内容 | 首期不支持宏、外链、公式与复杂重复区域，不静默转换 |
| 不完整数据 | 显式接受后生成部分数据版，不能隐藏状态 |
| 人工补值 | 允许本任务补充，标注来源，不回写图纸 |
| 默认保留期 | 数据集与文件建议 30 天，按业务及空间策略确认 |

本方案不包含模板库代码、数据库迁移、在线设置或部署修改。后续应先确认试点模板和上述业务决定，再拆分开发任务。
