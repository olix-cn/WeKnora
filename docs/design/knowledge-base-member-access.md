# 知识库成员权限

## 目标与状态

在一个空间内管理知识库访问，不要求业务用户为了保密资料创建和切换多个空间。

实现分为两层：统一授权与持久化基础，以及所有访问入口接入后的用户界面。
**当前开发树已挂载管理服务／HTTP／UI用于受控测试，尚未部署。** 下文“当前进度”的阶段记录保留演进历史，以文末最新状态和[测试部署清单](../knowledge-base-member-access-deployment.md)为准，不代表生产保密认证或全站数据撤回。
默认行为不变，不重写已有知识库、空间成员或跨空间分享。

## 用户规则

- **继承空间权限（默认）**：所有成员可读；贡献者管理自己创建的库；管理员／所有者管理全部库。可给其他有效成员单独授予编辑或管理权限。
- **指定成员**：普通成员必须在授权名单内。创建者不因曾创建该库而永久绕过名单；切换时界面默认加入创建者，删除时明确提示。
- 知识库授权：`viewer` 可阅读／检索／问答；`editor` 可维护库内内容；`admin` 可修改库设置与成员授权。授权不授予空间级配置、账号管理、创建其他库或跨空间分享能力。
- 空间 `viewer` 的只读上限保留：即使被误授予 editor/admin，也只生效为 viewer；界面应禁用这类选择并说明应先调整空间角色。
- 空间所有者／管理员保留对本空间所有库的管理权限，必须在权限面板常驻说明。系统管理员身份本身不额外绕过知识库策略；已获准切换空间的运维身份按现有空间角色处理。
- 仅可选择本空间有效、未删除的成员；移除／停用成员后授权立即失效，重新加入不得复活旧授权（绑定 membership ID）。
- 普通成员编辑者不能改变授权、删除整个库、修改模型／存储配置。知识库管理员不能将自己的库权限扩大为空间权限。
- API key 不冒充成员。受限库默认拒绝无用户的 API key／IM／嵌入式入口；后续若需要机器授权，须独立设计、明确授权，不自动沿用旧的全空间 key。
- 受限库不得通过跨空间共享或共享智能体绕过；已有分享时切换应拒绝并要求先解除相关分享。第一版不自动删除既有分享。

## 持久化与并发

- `knowledge_base_access_policies`：每库一条模式／版本；没有记录等价于继承。
- `knowledge_base_member_grants`：按知识库／用户唯一，绑定当前有效 membership ID，权限使用 viewer/editor/admin。
- 策略和名单整体原子替换。以版本号作乐观锁，冲突要求重新加载，不按最后保存者静默覆盖。
- 锁定知识库后重新加载操作者、当前成员关系及授权，不能信任客户端角色、creator_id 或旧界面权限。
- 成员 ID、KB/空间归属、模式、权限、重复用户与名单上限均在服务端检查。
- 所有策略变更经独立服务统一授权；repository 只提供事务原语，不作为可直接暴露的 API。
- down migration 若仍有受限策略或显式授权必须拒绝，防止回退后静默开放资料。上线仍需单独授权、备份与迁移评审。

## 必须统一覆盖的入口

1. 列表、最近访问、置顶、切换器、智能体编辑器选择器与 @ 提及：先过滤再计算数量／分页，不泄露库名和文档标题。
2. 知识库详情／设置，文档／分块／FAQ／Wiki／图片，批量读取与搜索。
3. RAG 与 Agent 知识范围解析、检索、原文读取、引用和历史引用文件代理；保留当前身份，不因 execution tenant 改变而授权。
4. 单文件预览／下载、批量下载、resource:// 文件代理、签名 URL。不得用“同空间文件”捷径绕过库绑定与当前权限。
5. 上传、编辑、删除、重解析、跨库移动／复制、模型配置、共享及授权管理分别按 editor/admin 边界处理。
6. API key、IM、嵌入式聊天、MCP endpoint、自动化和子 Agent：真实身份与机器能力分别校验，无身份不得继承管理员能力。
7. 已入队任务仅延续明确批准的操作，不把后台任务 grant 当成用户新请求的授权；新下载仍检查当前权限。
8. 数据源同步、Wiki 后台等内部任务不因缺少用户被误判为外部成员；必须使用独立的、精确 KB 的可信任务范围。

## 接入验收门槛

- 默认模式升级前后行为不变；指定成员外的用户通过手工拼 ID、批量 API、智能体、引用、文件 URL 均不能访问。
- 创建者移出名单不再访问；空间管理员明确保留管理；viewer 无法借显式编辑授权写入。
- 编辑者只改内容，管理员才改策略；跨空间 ID／成员与客户端伪造角色拒绝。
- 撤权、停用、移除后重新加入、并发保存、保存异常回滚、未知策略／角色、缺少调用者全部覆盖。
- 分享／共享智能体和 API key 无旁路；列表分页无隐藏项目计数泄露。
- 前后端完整回归、类型检查、关键接口集成测试及浏览器合成成员验收完成后才开放开关。

## 当前进度

- 已实现独立策略类型、纯授权决策、事务持久化和 PostgreSQL 140／SQLite 56 迁移基础。迁移不插入旧库策略，不修改旧库／成员。
- 已覆盖默认／受限模式、创建者移出名单、管理员恢复权限、viewer 上限、伪造调用者角色、成员移除重建、停用／删除、版本冲突、非法成员、写失败整笔回滚、缺迁移拒绝及 SQLite 回退保护测试。
- 成员查询已通过现有知识库／分享 repository 与 service 接入 `ResolveKB` 和 `KBPermissions`，优先于同空间、已有读取 grant 和共享智能体回退；同一操作按 KB/所属空间缓存结果，新操作重新读取。没有新增配置入口。
- 本空间列表／共享智能体来源列表在数量与 pin 丰富前过滤，组织共享列表和 ID 列表同样过滤。问答模型选择、批量文档／分块读取、检索范围与建议问题等复用统一授权；建议问题的 KB 查询失败不再降级为仅按空间读取。
- 文件侧增加 resource 成员校验：KB 代理、同空间 raw `/files`、聊天文件／附件、匿名 `/r` 及旧 HMAC 代理均接入当前策略。已注册物理别名重新查 catalog 绑定；旧未注册原文件查知识记录归属。当空间已有受限策略，而未注册衍生文件无法证明 KB 归属时，raw 路径保守拒绝，不能仅凭存储路径开放。多库复用同资源需满足全部受限归属，不能通过消息附件绑定降密。
- 匿名短链接在签发及解析时拒绝受限资源，旧短链接也检查当前状态。catalog 包装的 `GetFileURL` 在回退厂商 URL 前也检查匿名访问，不能因 APP_EXTERNAL_URL 为空而跳过；未走 catalog 的原生云 URL、通道自有签名仍须继续审计，不能称所有公开文件路径已封闭。
- 可信后台任务延续只认精确 KB 的 task grant，不把普通读取／shared-agent grant 当 task；客户端读取仍需当前策略。
- 写入守卫已初步区分库级 editor 内容维护与 admin 设置维护：上传、FAQ、分块、Wiki、标签及文档批处理接入；有明确策略时不因空间 RBAC 处于日志模式而放行。库复制／移动的 source/target 解析不再省略成员策略适配，但其中旧创建者检查和完整操作矩阵仍需继续对齐。
- 对外分享仍使用原空间角色／创建者守卫，不因库级 admin 自动放宽；ShareKnowledgeBase 对受限库直接拒绝。Agent 原文／分块读取在已捕获 search targets 之外重新检查当前成员策略，避免会话中途撤权后继续凭旧范围取数。
- `/files`、`/r` 与旧 HMAC 文件代理改为 `private, no-store`，避免新响应被共享缓存长期保留。不能撤销之前已下载／缓存的内容。
- 已实现未注册的管理 service／handler：仅当前有效的人类库管理员能读取／整体替换授权，保存时在锁内重新授权；分页成员搜索先授权，只返回本空间有效账号 ID／用户名／角色，不返回邮箱或内部 membership ID。请求要求版本及完整名单，拒绝未知字段／超限请求；409 区分并发修改和分享冲突，数据库错误不回显。
- 管理保存、知识库分享、智能体分享和已分享智能体范围更新统一先锁空间行，再锁 KB／成员；restricted 切换遇直接分享或覆盖本库的 selected/all 智能体分享时拒绝，反向创建分享／扩范围也拒绝。分享更新只允许 permission／updated_at，不允许更换分享对象绕过检查。事务级审计只记 mode／version／人数，审计失败整笔回滚，不记录名单／邮箱／正文。
- 回显名单过滤失效成员；旧页面保存遇 membership ID 已更换拒绝，需先移除旧授权再明确添加新成员，避免移出再加入后由旧表单复活授权。
- PostgreSQL 17 隔离实库已使用真实 PG140 SQL 验证 up/down、受限／显式 grant 回退拒绝、多连接双保存／KB分享／Agent分享／scope竞争和撤权，连续3轮 race通过。另以独立连接持有空间行锁，验证管理保存确实触发 lock_timeout（55P03），释放后成功；并非只验证单连接调度。基础模型表为测试 AutoMigrate，不等于生产139→140全量升级演练。
- 已新增未挂载的 `KBMemberAccessPanel.vue` 和 API helper：默认加入创建者、受限变更确认、查看／编辑／管理、viewer 上限、分享／版本冲突提示、保存后清空旧私有名单，以及切换账号／空间时丢弃迟到响应。面板中英文字独立，未挂载到现有页面；其他语言当前回退英文，正式开放前仍需本地化评审。
