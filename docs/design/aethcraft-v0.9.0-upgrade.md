# AethCraft 升级至上游 v0.9.0

本次以 Tencent/WeKnora 正式发布标签 `v0.9.0`（`f17ee8a8da901bd658a4cb25f40b5fd41adbfdd7`）为基准，合入此前上游基线 `25cdf4520` 之后的 16 个提交。发布日期为 2026-10-29；本地升级日期为 2026-11-03。

此前本地虽标注 0.8.3，已经同步了大量 0.9.0 开发阶段代码。因此应区分正式版本全部功能与此次实际补入的功能。

## 此次实际补入

- **空间默认设置**：统一指定对话、辅助生成、Embedding、Rerank、视觉和语音模型及默认搜索引擎。资源显式选择优先于空间默认，空间未设置时继续回退至部署默认或可用模型。辅助生成模型留空时跟随默认对话模型。
- **助手入口引导**：升级用户可看到一次助手入口提示，新用户引导也包含助手入口。
- **持久化审批状态**：审批已挂起时显示等待处理和有效期，避免误导性的短倒计时。
- **Lite 本机操作审批**：改进删除文件与扩大沙箱目录访问范围的确认和会话授权；默认会话目录位于用户目录 `.weknora/sessions`。此项主要用于 Lite 桌面版，不改变当前标准版 Docker 部署方式。
- **模型兼容性**：识别、过滤并校验 OpenAI 兼容响应中的 DSML 工具调用；保留 Ollama 最后流片段的结束原因；最终回答汇总关闭额外思考。
- **可靠性修复**：MCP 对话缺少完成事件时报错、限制 WeKnoraCloud 视觉响应大小、助手维护 Markdown 时保留空白和缩进、SQLite 空分词查询继续向量检索、修正 BLEU 和 NDCG 评估。
- **发布文档**：补充助手、多智能体协作、自动化、执行权限、升级须知和 0.9.0 演示素材。

## 0.9.0 正式版本整体重点

工作助手、多智能体协作、一次性/Cron 自动化、只读/修改前确认/自动执行权限、持久化审批、按用户复用沙箱、后台 Shell 任务，以及数据源、图片处理、文档解析和检索改进。上述大部分已经在此前同步的开发代码中存在。

完整说明见 [v0.9.0 发布说明](../../website-docs/07-releases/v0.9.0.md) 和 [CHANGELOG](../../CHANGELOG.md)。

## 定制合并

- 保留 AethCraft 标识、色彩、工业登录页和记住账号密码功能，以及已调整的用户菜单。
- 新增助手引导文字沿用 AethCraft 名称。
- 文档首页支持新版视频选择，同时保留已有 AethCraft 产品视频；上游发布视频明确标注为官方演示。
- 修正能力键一致性测试对 Windows CRLF 换行的解析，不修改运行时业务逻辑。

## 本地数据与运行环境

- 此前 PostgreSQL 已在迁移 133，本次只需 `000134_tenant_default_settings`，为 `tenants` 增加可空 JSONB 列 `default_settings`。
- 不自动填写新默认设置，不批量替换智能体、知识库中已保存的模型。
- 保留本机模型、重排服务接入、管理员、知识库及 Docker 沙箱配置。
- 启动脚本从 `VERSION` 读取版本并注入当前 Git 提交，避免更新代码后界面继续显示旧版本。
- 升级前数据库、文件存储、部署配置和旧程序备份保存在 Git 忽略的 `.local-run/`。
