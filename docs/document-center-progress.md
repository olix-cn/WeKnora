## 2026-11-12 新一轮：聊天 EBOM 与模板库改版（已隔离移植部署测试服）

- 模板库移除内置示例卡片和“从已保存的 BOM 结果生成”表单；已发布模板置顶卡片，右侧按钮打开鉴权 Blob 预览抽屉，草稿／停用版分区，原生文件选择改为统一 TDesign 上传按钮。旧内置样例 URL／历史任务保留兼容，但不在目录宣发。
- 新聊天工具 `document_templates` 查询当前空间已发布版本，`generate_ebom` 从同会话当前引擎轮次或已完成消息的完整 schema/data 导入，模型不提交表格值。当前轮通过引擎只读上下文提供真实 assistant message ID／先前已完成轮次；生成后返回任务深链接。源消息完成前，浏览器下载拒绝；完成后仍按来源权限校验。工具仅在文档表就绪、本人会话、非 API key、非共享只读／技能安装模式注册，不修改在线智能体配置。
- 运行提示在模板 EBOM 场景优先使用固定工具而非 xlsx Skills／脚本／Excel 子任务。不自动调用额外 MCP 补页；Agent 按完整分页契约读取，程序验证后消费。该入口不是已完成真实 CAD 在线验证。
- `BuildEBOM` 按精确图号引用构建有向结构、全局环检查、唯一根／可达性校验、同代号名称／材料／单位冲突检查；重复图号／版本冲突、多表歧义、多个根／孤立图、缺少数量、非法小数或深度／输出预算超限时阻塞。重复使用的子总成按结构路径分别展开，不做采购汇总。
- 固定计算：源数量按每直接父项用量，单台＝路径用量逐级乘积，多台＝单台×用户生产台数（1–1000000），十进制有理数无浮点误差。模板“数量”投影单台量，原“本级数量”另列保留。生产台数／一套图纸／每父项口径为显式工具参数，模型必须向用户确认，不从数据猜测。
- 支持固定语义表头：代号／图号、名称、材料、数量／单台数量、多台数量、序号、层级、父项、版本、单位、单重／总重、备注。只对明确支持的表头投影；单重／总重保留源值，不推测重量单位或任意 Excel 计算公式。原始独立来源列、源状态和结构／计算说明继续附表。
- 关键限制：当前实测 MCP schema 只有文件路径／表／物理列等，未提供权威 drawing_number、document_kind、quantity_basis；新适配只在结构化结果确实提供时使用这些值。文件名首段只能当部分身份依据，不按“总成”等名字猜关系；类型未知／外购件与缺图无法区分／模板要求缺失字段则标部分，并要求明确接受。用户规定目录是一套图纸不能替代结构证据，多个根仍拒绝。完整原生 EBOM／MCP 身份字段适配与真实 CAD 端到端验收未完成。
- 无数据库迁移；数据集 payload 增加图纸／源行／列身份。为避免 AgentService→文档生成→SessionService→AgentService 循环，生产文档授权改为同等严格的 SessionRepository 本人读取适配；Dig DryRun 全依赖图测试通过。
- 验证：documentgen／agent／repository／handler／router／container 六包全量 race、service 文档定向 race 通过，service 全量约 118 秒通过；agent 全子树单测、相关 vet／差异 lint 通过。开发前端 2744 项（2743 通过／1 跳过）、type-check／build 通过；WebKit 合成身份 mock API 验证引导发布、卡片、预览抽屉、移除示例／手动导入，无运行错误。2026-11-12 已基于运行 v0.9.0 定制版本隔离移植部署，仅 app/frontend 更新，无迁移；部署基线前端 2410 项（2409 通过／1 跳过），相关全量／race／vet／编译与上线检查通过。未使用真实账号执行在线聊天生成或真实 MCP 读写，业务端到端仍待验收；开发未提交／推送。

## 已实现

- “文档中心”统一入口和“我的文件 / 模板库 / 生成任务”页签。
- `/platform/documents` 为新入口，原 `/platform/artifacts` 保持同名路由的别名，查询筛选不丢失。
- 我的文件直接复用原产物列表、预览、下载、删除及会话归属检查，不复制文件或伪造聊天。
- 文档中心不以沙箱开关作为整个页面的前置条件；后端已有文件授权逻辑不变。
- 内置工程 BOM v1 样例目录和合成试填文件下载。样例不读取业务文件，也不保存到产物库。
- 固定 Go Excel 渲染核心，使用仓库已有 excelize 依赖，不调用模型或脚本。保留文本图号、来源和单元格状态，部分结果须明确接受；渲染后重新打开核对明细值且禁止数据公式。
- 模板目录与样例下载仅对认证空间用户开放；API key 默认拒绝。没有开放客户端提交任意业务数据、路径或代码的生成接口。
- 旧后端不支持新样例接口时，模板页显示可重试错误，不伪造已加载模板。
- 已接通内置模板的受限业务流程：粘贴本人会话链接／ID，查找已完成消息中的完整 BOM schema/data 页集，后台程序导入，再明确接受部分数据后生成。浏览器仅提交来源坐标，不提交表格值；不调用模型、CAD 或动态脚本。
- 已编写 PostgreSQL 137、SQLite 53 的新数据集与生成任务迁移。没有应用迁移时功能保持关闭；测试只在临时 SQLite 库应用脚本。
- 不可变数据集按本人／空间归属保存，生成、下载和列表重新检查来源会话／消息访问。仅支持本人来源，不能导入管理员只读回退或他人的会话。
- 任务保存幂等请求键，相同请求重试不重复生成；允许内置或已发布不可变版本，同名独立任务不合并为文件版本。生成中断后显示明确状态，不自动重跑。
- 文件复用现有 FileService 与 ResourceCatalog，绑定真实生成任务作为文件所有者，不伪造消息。“我的文件”统一列出聊天和模板文件，预览、下载、删除按来源分流；删除保留任务 tombstone。
- 导入时验证分页连续／终页／快照身份／全列选择／物理列及表行数，保留源表列的独立身份，不自动把同名列视为同义；其他源表列明确标为“不适用”，不是已确认空白。
- 管理员上传 `.xlsx` 草稿，手填工作表／表头行／目标列字母及准确表头文字；浏览器本地私有预览。配置后下载 30 行合成试填，确认所有样例和业务数据已清理后才能发布；重新保存配置使试填状态失效。
- 已于 2026-11-12 隔离移植至测试服的简化配置：默认展示工作表选择及原文件表头候选卡，自动生成字段标识和目标列；用户确认表头、勾选要填栏目后，一键保存并下载试填。手填坐标收进高级设置。已有草稿也可重新读取候选，仅创建者管理员可读，不新增迁移；候选不是语义推断或自动发布，后端仍验证原表头／明细空白和不支持布局。
- 模板状态为 draft → configured → tested → published → disabled。发布后不允许修改布局或文件，修改需重新上传新版本；版本号在空间／模板族内唯一。普通成员只见已发布版本，草稿管理仅限创建者且需管理员权限。
- 用户导入数据后可选已发布模板，并逐项明确绑定独立来源列；未绑定或无效绑定在预约任务前拒绝。自定义模板始终附加“源表明细 / 生成说明 / 源单元格状态”，不因少选字段丢失原数据；保留首明细行目标单元格样式、行高及原列宽，并重开核对输出值、状态与来源。
- 自定义模板仅支持表头紧接的一个空白明细区，下方不允许旧数据／页脚，不插删行、不执行公式。拒绝公式、宏、外链、图片／图表、结构化表、隐藏行列／工作表及其他复杂对象；限制上传与解压大小、ZIP 部件、XML、坐标、单元格和重复输出文本预算，不静默剥离不支持特性。
- 乐观状态更新检查旧状态／配置 hash／更新时间；任务预约与停用事务串行，停用后禁止新预约，但不取消先前任务或阻断已有结果下载／同键查询。
- 已编写 PostgreSQL 138、SQLite 54 的模板版本表迁移，仅在临时 SQLite 测试应用；`custom_templates_available` 明确返回 true 才显示上传／选择功能。

## 当前接口

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/api/v1/document-center/templates` | 返回内置模板；仅数据库及存储就绪时 `generation_available=true` |
| GET | `/api/v1/document-center/templates/engineering_bom_v1/preview` | 固定合成数据生成 Excel，无持久化、无 MCP 调用 |
| GET | `/api/v1/document-center/sources?session_id=...` | 本人会话最近 50 条消息中的可导入 BOM 页集摘要 |
| POST | `/api/v1/document-center/datasets/import` | 提交 session_id/message_id/result_id，程序从持久化结构化结果导入 |
| POST | `/api/v1/document-center/tasks` | 指定 dataset_id、不可变 template_id、request_key、accept_partial 与自定义 bindings |
| GET | `/api/v1/document-center/tasks` | 本人的分页任务列表 |
| GET / DELETE | `/api/v1/document-center/tasks/:id/file` | 校验来源和任务归属后下载／删除同一文件 |
| GET / POST | `/api/v1/document-center/custom-templates` | 可见模板列表／管理员上传新草稿（可指定 base_version_id） |
| GET / PUT | `/api/v1/document-center/custom-templates/:id/layout` | 读取可见布局／创建者管理员保存草稿配置 |
| GET | `/api/v1/document-center/custom-templates/:id/inspection` | 创建者管理员私有读取工作表／原文表头候选 |
| POST | `/api/v1/document-center/custom-templates/:id/test` | 私有合成试填下载并记录测试通过 |
| POST | `/api/v1/document-center/custom-templates/:id/publish` | 必须 sample_cleared=true 且已测试才发布 |
| POST | `/api/v1/document-center/custom-templates/:id/disable` | 停用已发布版本，保留历史输出 |

接口位于现有认证和 API key 默认拒绝中间件之后，检查当前调用者的空间与用户身份。文档中心两阶段迁移共新增三张表，无源图纸／模型配置变更；测试服经备份后顺序迁移至 138（同时包含前序 135/136），自动迁移仍关闭。接口尚需正式 Swagger 契约同步，不创建后台队列或模型调用。
